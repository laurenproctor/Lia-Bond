# Prompt 1 — Build the Lia foundation

Read `CLAUDE.md` and all files under `docs/`.

Create a Next.js 16, React 19, TypeScript, Tailwind CSS 4 application for Lia. Build the shared application shell, sidebar navigation, organization/location switcher, page headers, KPI cards, badges, filter controls, tables, timelines, detail panels, response composer, and chart containers.

Use realistic typed mock data. Create all routes listed in `CLAUDE.md`, but initially render route-specific page headers and skeleton layouts only.

Requirements:
- Strict TypeScript
- Reusable components
- Accessible controls
- Responsive from 1440 px to 768 px
- No external database yet
- No integration calls yet
- Use the reference images in `public/reference-screens/`

After implementation, run lint, type-check, and build. Fix all errors.
